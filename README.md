# FindMyBiz

Get small businesses recommended when customers ask AI assistants (ChatGPT, Claude, Grok, Google AI).

## Structure
- `index.html`: landing page
- `waitlist.html`: early-access signup (form not yet connected)
- `css/findmybiz.css`: shared styles
- `logo.svg`: logo

## Run locally
Open `index.html` in a browser.
