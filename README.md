# FindMyBiz

Get your business recommended by AI assistants (ChatGPT, Claude, Grok, Google AI).

Brand name: FindMyBiz. Update `index.html`, `waitlist.html` and this file if it changes.

## Structure
- `index.html` landing page
- `waitlist.html` early-access signup
- `css/styles.css`, `js/main.js`, `js/optional.js` shared styles and scripts copied from the Prospera site
- `icon.png` placeholder icon

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.
